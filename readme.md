# Telegram Bot для календаря цикла

Этот бот ведёт календарь менструального цикла и напоминает:

- в день первого дня месячных — зафиксировать начало кровотечения
- в день последнего дня месячных — зафиксировать окончание кровотечения
- на 10-й день цикла — напомнить заказать таблетки
- с 15 по 25 день цикла в 7:00 и 19:00 — напомнить пить таблетку

## Установка

1. Создайте виртуальное окружение:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Создайте файл `.env` на основе `.env.example`:
   ```bash
   copy .env.example .env
   ```
4. Замените `YOUR_BOT_TOKEN_HERE` на токен, полученный у @BotFather.

## Команды бота

- `/start` — приветствие и описание
- `/first_day YYYY-MM-DD` — сохранить дату первого дня месячных
- `/last_day YYYY-MM-DD` — сохранить дату последнего дня месячных
- `/status` — показать текущий день цикла и ближайшее напоминание
- `/help` — справка

## Запуск

```bash
python bot.py
```

## Примечание

Бот сохраняет даты в локальном JSON-файле в папке `data/`, поэтому для одного пользователя это удобно для ежедневных напоминаний без базы данных.
