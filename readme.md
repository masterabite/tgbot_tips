# Telegram Bot для календаря цикла

Этот бот ведёт календарь менструального цикла и напоминает:

- в день первого дня месячных — зафиксировать начало кровотечения
- в день последнего дня месячных — зафиксировать окончание кровотечения
- на 10-й день цикла — «Начинается подготовка к священным дням»
- с 15 по 25 день цикла в 7:00 и 19:00 — «Дюфастон»

## Установка

1. Создайте виртуальное окружение:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Создайте файл `.env` на основе `.env.example`:
   ```bash
   copy .env.example .env
   ```
4. Замените `YOUR_BOT_TOKEN_HERE` на токен, полученный у @BotFather.

## Кнопки бота

- «Первый день» — сохранить дату начала месячных
- «Последний день» — сохранить дату окончания месячных
- «Узнать день» — показать текущий день цикла
- «Календарь» — посмотреть историю по месяцам
- «Дополнительное напоминание» — выбрать время ещё одного напоминания сегодня

Нажми кнопку даты, затем отправь дату в формате `ДД.ММ.ГГГГ`.
Стрелки под календарём листают месяцы; дни месячных выделены цветом `#FB6F92`.
История сохраняется и пополняется при внесении новых дат.
Для дополнительного напоминания введи будущее время сегодня в формате `ЧЧ:ММ` по Москве.
Утром бот случайно обращается «Женечка», «Солнце», «Дорогая», «Кошка»,
«Зайчик», «Малышка» или «Мышка» и напоминает принять дюфастон;
вечером присылает «Не забудь принять Дюфастон».
У напоминаний о приёме есть кнопки «Готово» и «Отложить». Отложенное напоминание
можно перенести ещё на 30 минут или на час; повтор будет приходить, пока не нажать «Готово».

Команды `/start` и `/help` также доступны в чате.

На 10-й день цикла бот отправляет напоминание «Начинается подготовка к священным дням».
С 15-го по 25-й день в 7:00 и 19:00 по московскому времени бот отправляет напоминания
о приёме препарата; утреннее обращение выбирается случайно.

## Запуск

```bash
python bot.py
```

## Примечание

Бот сохраняет даты в локальном JSON-файле в папке `data/`, поэтому для одного пользователя это удобно для ежедневных напоминаний без базы данных.
